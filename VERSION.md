
# Registro de versiones — SismoListo

## Política de versionamiento

Se aplica Semantic Versioning (MAJOR.MINOR.PATCH).

- MAJOR: cambios incompatibles.
- MINOR: nuevas funcionalidades compatibles.
- PATCH: correcciones sin cambios de funcionalidad.
